# Splack
رابط فارسی راست‌به‌چپ برای دستیار هوش مصنوعی چندحالته با Cloudflare Pages Functions.

## حالت‌ها
- Eagle: مکالمه و تحقیق؛ جست‌وجوی وب در صورت تنظیم سرویس جست‌وجو
- Gecko: برنامه‌نویسی و کمک فنی
- Crocodile: تولید تصویر از متن با FLUX Schnell

## راه‌اندازی Cloudflare Pages
در پروژه Pages به Settings → Variables and Secrets برو و کلیدها را به‌صورت Secret اضافه کن. کلیدها را هرگز در کد فرانت‌اند یا GitHub قرار نده.

### مدل متنی (حداقل یکی لازم است)
- OPENROUTER_API_KEY — مسیر اصلی؛ مدل پیش‌فرض openrouter/free
- GROQ_API_KEY — مسیر جایگزین؛ مدل پیش‌فرض openai/gpt-oss-20b
اختیاری: OPENROUTER_MODEL و GROQ_MODEL برای انتخاب مدل.

### جست‌وجوی وب (برای Eagle)
یکی از این موارد:
- TAVILY_API_KEY
- BRAVE_API_KEY
- SEARXNG_URL — آدرس پایه نمونه SearXNG با خروجی JSON
اگر هیچ‌کدام تنظیم نشوند، مدل می‌تواند پاسخ بدهد اما منابع وب ارائه نمی‌شوند.

### ساخت تصویر (برای Crocodile)
- FAL_KEY — کلید fal.ai؛ تولید تصویر ممکن است اعتبار مصرفی داشته باشد و رایگان نامحدود نیست.

## نکات
- تاریخچه گفت‌وگو در حافظه محلی همان مرورگر ذخیره می‌شود؛ فعلاً همگام‌سازی بین دستگاه‌ها یا حساب کاربری وجود ندارد.
- هر درخواست چت تلاش می‌کند از سرویس جست‌وجوی تنظیم‌شده نتیجه بگیرد، سپس مدل پاسخ را می‌سازد.
- مسیریابی متن: OpenRouter و در صورت عدم پاسخ‌دهی، Groq.
- سهمیه مدل‌های رایگان محدود و متغیر است؛ استفاده رایگان نامحدود تضمین نمی‌شود.
