# Splak
رابط فارسی راست‌به‌چپ برای دستیار هوش مصنوعی چندحالته با Cloudflare Pages Functions.

## حالت‌ها
- Eagle: مکالمه و تحقیق؛ جست‌وجوی وب در صورت تنظیم سرویس جست‌وجو
- Gecko: برنامه‌نویسی و کمک فنی
- Crocodile: تولید تصویر از متن

## راه‌اندازی Cloudflare Pages
در پروژه Pages به Settings → Variables and Secrets برو و کلیدها را به‌صورت Secret اضافه کن. کلیدها را هرگز در کد فرانت‌اند یا GitHub قرار نده.

### مدل متنی و تصویری
- ONE_X_AI_API_KEY — کلید API از حساب 1xAi؛ برای چت و تولید تصویر
- ONE_X_AI_MODEL — اختیاری؛ پیش‌فرض gpt-4o-mini
- ONE_X_AI_IMAGE_MODEL — اختیاری؛ پیش‌فرض gpt-image-2
- OPENROUTER_API_KEY و GROQ_API_KEY — مسیرهای جایگزین اختیاری؛ فقط در صورت داشتن حساب و مجوز استفاده
- OPENROUTER_MODEL و GROQ_MODEL — شناسه مدل‌های جایگزین اختیاری

### جست‌وجوی وب (برای Eagle)
یکی از این موارد:
- TAVILY_API_KEY
- BRAVE_API_KEY
- SEARXNG_URL — آدرس پایه نمونه SearXNG با خروجی JSON
اگر هیچ‌کدام تنظیم نشوند، مدل می‌تواند پاسخ بدهد اما منابع وب زنده ارائه نمی‌شوند.

## نکات
- تاریخچه گفت‌وگو در حافظه محلی همان مرورگر ذخیره می‌شود؛ فعلاً همگام‌سازی بین دستگاه‌ها یا حساب کاربری وجود ندارد.
- هر درخواست چت تلاش می‌کند از سرویس جست‌وجوی تنظیم‌شده نتیجه بگیرد، سپس مدل پاسخ را می‌سازد.
- ترتیب مسیریابی متن: 1xAi، سپس OpenRouter، سپس Groq (اگر کلیدهایشان تنظیم شده باشند).
- سرویس 1xAi شخص ثالث و مستقل است؛ پیش از استفاده عمومی/تجاری، شرایط فعلی آن و مجوز ارائه خروجی به کاربران نهایی را بررسی کنید.
- استفاده از APIها و مدل‌ها ممکن است هزینه داشته باشد؛ رایگان نامحدود تضمین نمی‌شود.
